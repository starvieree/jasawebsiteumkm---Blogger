Firestore Security Rules yang Disarankan

Pastikan Anda memasang aturan ini di Firebase Console > Firestore Database > Rules:

service cloud.firestore {
  match /databases/{database}/documents {
    match /paket_harga/{docId} {
      allow read: if true;
      allow write: if request.auth != null;
    }
    match /layanan/{docId} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}
